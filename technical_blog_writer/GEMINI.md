# Technical blog workflow — Gemini CLI

When asked to start, resume, or continue a technical blog:

1. Read `AGENTS.md` (the shared operating rules).
2. Read `harness/adapters/gemini-cli.md` and `harness/contracts/host-capabilities.md`.
3. Read the manifest/workflow/policies referenced there, then run the saved-state startup protocol.

Use Gemini CLI's actual tools and MCP configuration; do not assume Codex tool names or credentials. If structured questions are unavailable, ask in chat and wait. Do not start collection merely because this file was loaded, and do not activate the workflow for unrelated coding tasks.
